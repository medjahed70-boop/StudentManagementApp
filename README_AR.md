# 📚 برنامج إدارة التلاميذ - المرحلة الثانوية

## 🎯 نظرة عامة

برنامج احترافي متكامل لإدارة بيانات التلاميذ والحضور والغياب والوثائق في المؤسسات التعليمية الثانوية.

---

## ✨ الميزات الرئيسية

### 👥 **إدارة التلاميذ**
- ✅ إضافة وتحديث بيانات التلاميذ
- ✅ جلب البيانات حسب القسم
- ✅ البحث والتصفية
- ✅ شطب من القوائم

### 📋 **الحضور والغياب**
- ✅ تسجيل يومي للحضور والغياب
- ✅ حساب ساعات الغياب تلقائياً
- ✅ **إنذارات آلية:**
  - إنذار أول (3 أيام)
  - إنذار ثاني (10 أيام)
  - إعذار (17 يوم)
  - شطب من القوائم (32 يوم)

### 📊 **التقارير والإحصائيات**
- ✅ التقرير اليومي
- ✅ التقرير الشهري
- ✅ إحصائيات الغيابات
- ✅ تقارير المخالفات

### 📧 **نظام الإشعارات**
- ✅ بريد إلكتروني تلقائي للأولياء
- ✅ إشعارات حسب مستويات الغياب
- ✅ رسائل احترافية بالعربية

## 🛠️ المتطلبات

- ✅ **نظام التشغيل:** Windows 7 أو أحدث
- ✅ **.NET Framework:** 4.7.2 أو أحدث
- ✅ **قاعدة البيانات:** SQL Server 2012 أو أحدث
- ✅ **بريد إلكتروني:** Gmail أو بريد يدعم SMTP

## 📦 التثبيت والتشغيل

### 1️⃣ **إعداد قاعدة البيانات**
```bash
# افتح SQL Server Management Studio
# نفّذ الملف: Database/CompleteSchema.sql
```

### 2️⃣ **تحديث ملف الإعدادات**
```xml
<!-- في App.config -->
<add name="DefaultConnection" 
     connectionString="Server=.\\SQLEXPRESS;Database=StudentManagementDB;..." />
```

### 3️⃣ **تثبيت المكتبات المطلوبة**
```bash
Install-Package iTextSharp
```

### 4️⃣ **تشغيل البرنامج**
```bash
# اضغط F5 في Visual Studio
```

### 5️⃣ **تسجيل الدخول**
```
اسم المستخدم: admin
كلمة المرور: admin123
```

## 📋 الملفات الرئيسية

### 📂 **Database/**
- `CompleteSchema.sql` - تعريف قاعدة البيانات الكاملة

### 📂 **Core/**
- `DatabaseConnection.cs` - فئة الاتصال بقاعدة البيانات
- `Student.cs` - نموذج بيانات التلميذ
- `AbsenceSummary.cs` - نموذج ملخص الغيابات

### 📂 **Services/**
- `StudentManager.cs` - إدارة التلاميذ
- `AttendanceManager.cs` - إدارة الحضور والغياب
- `EmailService.cs` - خدمة البريد الإلكتروني
- `ReportGeneratorService.cs` - إنشاء التقارير
- `StatisticsService.cs` - الإحصائيات المتقدمة

### 📂 **Forms/**
- `LoginForm.cs` - نموذج تسجيل الدخول
- `MainForm.cs` - الواجهة الرئيسية
- `StudentManagementForm.cs` - إدارة التلاميذ
- `AttendanceForm.cs` - الحضور والغياب
- `ReportsForm.cs` - التقارير
